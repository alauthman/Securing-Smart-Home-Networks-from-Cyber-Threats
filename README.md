# Smart-Home Network Anomaly Detection (ML + Raspberry Pi + Docker)

This repository provides an **end-to-end, reproducible** pipeline to:
1) **ingest & preprocess** large smart-home cyber-physical datasets (CSV/JSON + optional PCAP conversion),
2) **train & evaluate** a machine-learning (ML) model (classification or anomaly detection),
3) **export** the trained model as an artifact,
4) **deploy** inference on **Raspberry Pi** using **Docker**,
5) **monitor & analyze** system performance (latency, throughput, CPU/RAM).

> ✅ Dataset is **NOT included** in this repo. Place your dataset under `data/raw/` and update the config in `configs/`.

---

## Repository layout

```
.
├─ configs/                  # YAML configs
├─ data/

├─ reports/                  # evaluation & system analysis outputs
├─ scripts/                  # one-command utilities
├─ src/shnet_ml/             # Python package

```

## Quick start (local)

### 1) Create a virtual environment
```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -U pip
pip install -r requirements.txt
```

### 2) Generate a synthetic dataset (for a quick smoke test)
```bash
python scripts/make_synth_data.py --out data/raw/synth/synth.csv --rows 5000
```

### 3) Preprocess
```bash
python scripts/preprocess.py --config configs/example_synth.yaml
```

### 4) Train + evaluate
```bash
python scripts/train.py --config configs/example_synth.yaml
python scripts/evaluate.py --config configs/example_synth.yaml
```

### 5) Export model
```bash
python scripts/export_model.py --config configs/example_synth.yaml
```

## Run inference service (local without Docker)

```bash
export SHNET_MODEL_PATH=models/model.joblib
uvicorn shnet_ml.serve.app:app --host 0.0.0.0 --port 8000
```

Test:
```bash
curl -X POST http://localhost:8000/predict \
  -H "Content-Type: application/json" \
  -d '{"rows":[{"pkt_size_mean":340,"conn_rate":1.2,"dns_qps":0.2,"proto":"TCP"}]}'
```

## Docker inference (recommended for Raspberry Pi)

### Build
```bash
docker build -f docker/Dockerfile -t shnet-ml-edge:latest .
```

### Run
```bash
docker run --rm -p 8000:8000 \
  -e SHNET_MODEL_PATH=/app/models/model.joblib \
  -v "$(pwd)/models:/app/models:ro" \
  shnet-ml-edge:latest
```

Or use Compose:
```bash
docker compose up --build
```

---

## Raspberry Pi notes

- Prefer Raspberry Pi OS 64-bit on Pi 4/5.
- Build the Docker image **on the Raspberry Pi** (simplest), or use multi-arch builds.
- If you will capture network traffic on the Pi (gateway mode), keep data volumes on an external SSD.

## Configuration

Configs live in `configs/*.yaml`.

Key fields:
- `dataset.raw_glob`: pattern(s) for raw input files
- `dataset.label_col`: label column name (optional for anomaly detection)
- `dataset.time_col`: timestamp column name (optional)
- `features.numeric_cols` / `features.categorical_cols`
- `task`: `classification` or `anomaly`
- `model`: model type and parameters
- `paths`: where to write processed data, models, reports

See `configs/example_synth.yaml`.

## System monitoring & analysis

Collect metrics (JSONL) while inference is running:
```bash
python scripts/monitor.py --out reports/monitor.jsonl --seconds 120 --interval 1
python scripts/system_report.py --monitor reports/monitor.jsonl --out reports/system_report.md
```

## Optional: PCAP → Features (using tshark)

If your dataset includes PCAP files, you can convert a PCAP into simple time-window features:

```bash
# Requires tshark installed on your machine:
#   Ubuntu/Debian: sudo apt-get install tshark
python scripts/pcap_to_features.py --pcap data/raw/cardiff/network.pcap --out data/raw/cardiff/pcap_features.csv --window 1
```

Then point your config's `dataset.raw_glob` to the generated CSV (or merge it with other tabular sources as needed).
